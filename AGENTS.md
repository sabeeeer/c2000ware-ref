# Repository instructions

- This repository is a read-only, source-only snapshot of TI C2000Ware.
- Do not rewrite or remove original TI copyright/license headers.
- Keep generated build outputs, PDFs, installers, and prebuilt binaries out of
  the repository unless the license and distribution route are explicitly
  reviewed.
- For recovery or offline use, start with `RECOVER.md`.
- For SDK layout and usage, read `README.md` and `docs/manifest.html`.
